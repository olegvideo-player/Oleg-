# ▶ Видеохостинг «Олег» (Версия 1.5)

Добро пожаловать, **Олегончане**! 

**«Олег»** — это авторский ретро-видеохостинг в ламповом стиле 2007 года, созданный с нуля прямо на телефоне. Никакой рекламы, скрытых дизлайков и платных подписок — всё сделано по-честному и для души.

🔗 **Открыть рабочий сайт:** https://olegvideo-player.github.io/Oleg-/

### Что умеет «Олег»
* **Студия загрузки:** добавление своих видео и обложек-превью прямо из галереи устройства.
* **Полноценные каналы:** настройка имени, описания, цвета и аватарки своего профиля, а также просмотр страниц других авторов и подписки.
* **Плейлисты и библиотека:** создание собственных подборок видео, список «Смотреть позже» и история просмотров.
* **Продвинутый плеер:** разворот на весь экран, выбор скорости воспроизведения, скачивание роликов, открытые счётчики лайков/дизлайков и ветки комментариев с ответами.
* **Удобство:** мгновенное переключение **Тёмной / Светлой темы** и выбор языка (**RU / EN**).  Обновление 1.3 теперь Олег теперь тоже приложение. Обновление 1.4 добавил чтобы к видео которые уже опубликованы можно было изменить превьюшку. Обновление 1.5 теперь появился Автомодератор и модерация добавилась кнопка пожаловаться и т.д
